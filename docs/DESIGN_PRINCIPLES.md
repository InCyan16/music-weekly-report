# 产品设计共识

## 黑胶旋转，而非进度条

音乐日记**刻意不使用**传统音乐 App 的进度条 / 滑块。

### 为什么

产品的核心视觉是黑胶唱机。在物理世界里，你不会拖动一条线来跳转——你会**用手旋转唱片**。交互应当延续这种拟物逻辑，而不是退化成通用播放器 UI。

### 交互映射

```
旋转唱片（顺时针）  →  快进
旋转唱片（逆时针）  →  后退
左右滑动唱片        →  切换当天播放历史中的歌曲
点击播放按钮        →  开始 / 暂停
```

### 界面表现

- **有**：当前时间 / 总时长文字（如 `1:23 / 3:45`）
- **无**：`<input type="range">` 进度条、可拖动的播放头
- **无**：「上一首 / 下一首」按钮组（切歌靠滑动手势 + 底部「下一首歌」）

### 有效播放计数

旋转唱片改变播放位置**不计入**累计播放时间。只有真实播放（含暂停后继续）才计入有效播放次数。这与「拖动进度条不计时」的规则一致，但实现介质是**旋转手势**而非滑块。
